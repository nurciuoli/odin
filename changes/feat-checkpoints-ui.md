- Hovering one of your messages in a session shows a small rewind icon. It replaces the message box with a prompt, like an agent question, with a timeline of the session's turns and four options: branch from that point in a new worktree, rewind the session (it moves to a new one and the original is archived), restore the files only (with Undo), or fork the conversation only. Keys 1–4, Enter and Esc work.
