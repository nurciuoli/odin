- Secrets vault for MCP servers: an MCP library spec can use `${secret:NAME}` in its args, environment, URL and headers, and Odin fills the value from `~/.odin/secrets.json` (mode 600) only when it launches a session, so tokens no longer sit in library files or `.mcp.json`. A session that needs a secret that isn't set refuses to start and says which one. API: `GET /api/secrets`, `PUT|DELETE /api/secrets/:name` (values are never returned). There is no screen for it yet.
