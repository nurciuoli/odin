- A Changes tab in the session's preview shows staged and unstaged files with their diffs. Stage, unstage or revert whole files, single hunks or picked lines, commit with a message drafted from the session, and group the changes by the turn that made them.
- The session header shows the branch with commits ahead and behind. Click it (or press ⌘B) to switch branches, open the session that has a branch in its worktree, create a branch, or fetch, pull and push. A switch with uncommitted changes asks whether to stash them (they come back when you return), carry them over, commit first, or start a new session on that branch. A diverged branch offers rebase or merge, then push.
- Files open from a session now have Code, Blame and History views. Blame shows who last changed each line, naming the Odin session and turn for commits a session made, with the commit on hover and a summary of who wrote the file. History lists the file's commits with each one's change to it.
- Type `@` in the ⌘K palette on a session to switch to one of its branches, start a new session on a branch, create a branch, restore, apply or drop a stash, or fetch, pull and push.
- Git actions: a repo can ask Odin to run commands before commits and pushes made from Odin, or on demand, with JSON files in `.odin/git-actions/`. A failing check before a commit shows its output in the Changes panel with "Ask Claude to fix", "Run again" and "Commit anyway". The Library has a Git actions tab listing every repo's actions, their last run and Run now.
