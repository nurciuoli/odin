- The session header shows the branch with commits ahead and behind. Click it (or press ⌘B) to switch branches, open the session that has a branch in its worktree, create a branch, or fetch, pull and push. A switch with uncommitted changes asks whether to stash them (they come back when you return), carry them over, commit first, or start a new session on that branch. A diverged branch offers rebase or merge, then push.
