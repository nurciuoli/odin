- Claude Code plugins can be imported into the library and exported back: `POST /api/library/import` reads a git address or a local folder and previews what it would add (skills, agents, commands as skills, hooks, MCP servers, warnings), `POST /api/library/import/:previewId` writes it, and `POST /api/library/plugin/:id/export` writes a plugin as a Claude Code plugin folder with secrets as placeholders. There is no screen for it yet.
