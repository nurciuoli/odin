- OAuth for remote MCP servers: add `"oauth": { "scope": "…", "clientId": "…" }` to an http MCP library spec and sign in once. Odin finds the server's sign-in endpoints, registers itself when the server allows it, keeps the tokens in `~/.odin/oauth.json` (mode 600), refreshes them, and sends them to whichever runtime a session uses; a session on a server that needs sign-in refuses to start and says so. API: `GET|DELETE /api/mcp/:id/oauth`, `POST /api/mcp/:id/oauth/start`. There is no screen for it yet. See `docs/plans/mcp-integration.md`.
